SỬA LỖI CHẠY LOCAL TỪ REPO GITHUB DESKTOP KHÔNG KẾT NỐI GOOGLE SHEETS

GitHub Desktop chỉ tải/đẩy mã nguồn. Nó không tự mang các Environment Variables từ Render về máy.

1. Đặt app_github_local_fixed.py vào repo và đổi tên thành app.py.
2. Cài thư viện:
   py -m pip install -r requirements_local_google.txt
3. Đổi env.example.txt thành .env.
4. Điền GOOGLE_SHEET_ID. Ví dụ link:
   https://docs.google.com/spreadsheets/d/ABC123XYZ/edit
   thì ID là ABC123XYZ
5. Tải file service account JSON từ Google Cloud, đổi tên service-account.json,
   đặt cùng thư mục app.py.
6. Mở service-account.json, copy client_email.
7. Mở Google Sheet -> Chia sẻ -> thêm client_email -> quyền Editor.
8. Bật Google Sheets API và Google Drive API trong đúng Google Cloud project.
9. Gộp nội dung gitignore_google_secrets.txt vào file .gitignore.
10. Kiểm tra trước:
    py test_google_sheet.py
11. Chạy ứng dụng:
    py app.py
    rồi mở http://127.0.0.1:8000

TRÊN RENDER
- Không upload service-account.json lên GitHub.
- Vẫn dùng Environment:
  GOOGLE_SHEET_ID
  GOOGLE_CREDENTIALS_JSON = toàn bộ nội dung file JSON trên một biến
- Save Changes rồi Manual Deploy -> Deploy latest commit.
