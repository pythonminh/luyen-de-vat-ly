BẢNG CÔNG THỨC
1. Góc bù nhau
sin(180° − α) = sin α
cos(180° − α) = −cos α
tan(180° − α) = −tan α
2. Định lý cos
a² = b² + c² − 2bc·cos A
3. Định lý sin
a/sin A = b/sin B = c/sin C
4. Diện tích tam giác
S = bc·sin A / 2
p = (a+b+c)/2
S = √[p(p−a)(p−b)(p−c)]
5. Lượng giác
sin²α + cos²α = 1
sin 30° = 1/2
cos 30° = √3/2
sin 45° = cos 45° = √2/2
sin 60° = √3/2
cos 60° = 1/2

Chọn một trong bốn phương án A, B, C, D.
