# UI V308

V308 is a safe first-pass visual redesign layer over the existing Flask application.

## Files

- `ui_v308.py` keeps the existing backend and decorates HTML responses with the new visual layer.
- `static/v308.css` contains the responsive design system.
- `static/v308.js` adds small non-destructive client enhancements.

## Preview

The branch is configured to run through `ui_v308:app`. Use `/ui-v308-preview` for the standalone visual preview, and `/` for the existing application with V308 styling injected.

## Rollout

`main` is unchanged. This branch is based on the current `main`, which already contains the commit `2af09285af2846cf3c3a0a9929f022cdf905d516` plus later updates. After visual approval, the next pass can move the redesign into the existing HTML structure and then merge to `main`.
