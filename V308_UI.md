# UI V308

This branch introduces a visual redesign layer without rewriting the existing Flask backend.

## What changed

- `ui_v308.py`: imports the existing `app` and decorates HTML responses from `/` with the V308 CSS/JS layer.
- `static/v308.css`: V308 design system, responsive cards/forms/tables and mobile styling.
- `static/v308.js`: non-destructive client enhancement layer.

The existing API routes and business logic in `app.py` are not changed by this first UI pass.

## Preview

When this branch is run with `gunicorn ui_v308:app`, open:

- `/ui-v308-preview` for the standalone V308 visual preview.
- `/` for the existing application with the V308 layer injected.

## Render

Do not change `main` yet. For a safe test, create a Render preview service from branch `ui-redesign-v308` and use:

```text
gunicorn ui_v308:app
```

After visual verification, the next phase can progressively move the redesign into the existing HTML rather than keeping it as a wrapper.
